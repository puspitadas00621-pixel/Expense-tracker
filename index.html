How to set up table in Supabase SQL Editor

1. Create a free project at supabase.com.

2. In your Supabase Dashboard, go to SQL Editor, paste this snippet, and click RUN:

-- Create Expenses Table
CREATE TABLE IF NOT EXISTS expenses (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  amount NUMERIC NOT NULL,
  category TEXT NOT NULL,
  date DATE NOT NULL,
  description TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Enable Row Level Security (RLS)
ALTER TABLE expenses ENABLE ROW LEVEL SECURITY;

-- Allow Public Access for Personal Expense Tracking
CREATE POLICY "Allow public full access" ON expenses
  FOR ALL USING (true) WITH CHECK (true);

3. Copy your Project URL & anon public API key from Project Settings -> API into the form above.
